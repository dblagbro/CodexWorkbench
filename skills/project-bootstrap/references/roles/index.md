# Role router

Read this small index when entering an enrolled project or when its task changes. Load only the modules needed for the next work, not every discipline. Roles are task perspectives, not permission grants or automatically spawned agents. The same agent may combine relevant roles; use separate specialists only for distinct authorized work/review.

| Task signal | Load |
| --- | --- |
| Scope, priorities, acceptance, milestones, costs, coordination | [Project lead](project-lead.md) |
| Boundaries, data/contracts, costly or irreversible design choices | [Architecture](architecture.md) |
| Implementation, scripts, APIs, full-stack changes, refactoring | [Engineering](engineering.md) |
| User workflows, information structure, visual/interaction design | [Product and UX](product-ux.md) |
| Actual browser UI, components, frontend states, accessibility | [UI development](ui-development.md) |
| Deployment, hosts, storage, backup, systems maintenance | [Operations](operations.md) |
| Routing, firewall/PAT, ingress, DNS, TLS, network changes | [Networking](networking.md) |
| Physical devices, hardware actuation or control limits | [Hardware](hardware.md) |
| Defects, risk-based QA, independent review, docs/help/release | [Quality loop](../quality-loop.md) |
| Alternatives, adoption economics, product direction or pivot | [Research and adoption](research-adoption.md) |
| Provider/user switch, stale chat, interrupted ownership | [Handoff](../shared-handoff.md) |
| Unattended request, cadence, runtime, blocker notifications | [Unattended work](../unattended.md) |

Enter with the task, constraints and concrete output; leave with changed artifacts, evidence, decisions and next action. At a role boundary, update a concise project checkpoint only when it adds useful information. Reuse still-valid module findings rather than rereading full files. Refresh changed/missing guidance or live-state facts. Project instructions and explicit current authorization govern every role. Do not install unused tools or create empty lifecycle documents to match a role list.
