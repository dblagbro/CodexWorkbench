# UI development

Load only for an actual user interface. Preserve the application's component system, semantics and accessibility conventions. Implement loading, empty, validation/error, progress/cancellation, stale/disconnected and recovery states along the primary workflows. Support keyboard use, useful labels/focus behavior and relevant screen sizes.

Use installed supported browser automation or Playwright to exercise real interactions and inspect rendering/screenshots with representative data. Cover consequential permissions/destructive actions and long labels/volumes. A successful build or mocked component test does not establish UI QA. Record tested browsers/workflows and gaps; do not add a browser package to a CLI-only project merely to fill a checklist.
